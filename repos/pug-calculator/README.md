# Pug Calculator

Pug Calculator is a SwiftUI iOS calculator starring Professor Pug, a cute animated mad scientist helper. The app includes a colorful laboratory interface, a numeric display in the pug's speech beaker, animated reactions for input, operations, results, resets, and errors, plus a tested pure-Swift calculator engine.

## Open in Xcode

1. Open `PugCalculator.xcodeproj` in Xcode 15 or newer.
2. Select the `PugCalculator` scheme.
3. Run on an iPhone or iPad simulator using iOS 17 or newer.

## Test the calculator engine

The calculator math engine is packaged separately so it can be tested on macOS or Linux with Swift Package Manager:

```sh
swift test
```
